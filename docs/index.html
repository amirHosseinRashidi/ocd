OCD: Obsessive-Compulsive Verification Protocol for Coding Agents

amirHosseinRashidi  ·  github.com/amirHosseinRashidi/ocd

Abstract

AI coding agents frequently suffer from premature task declaration — claiming completion before validating type correctness, test suite passing, or removing debug statements. We present OCD (Obsessive-Compulsive Verification Protocol), a 4-phase sequential auditing pipeline that forces AI agents to run strict verification passes before declaring task completion.

Pipeline Architecture

  • Phase 1 — Cleanliness: Audits modified files for leftover debug statements.
  • Phase 2 — Typecheck: Runs multi-language type verification (TypeScript, Rust, Python).
  • Phase 3 — Test Suite: Executes unit & integration tests.
  • Phase 4 — Git Diff Audit: Enforces change boundary controls and prevents scope creep.

CLI Usage

npm install -g ocd-agent
ocd --strict
